# Resido App Source

This is the source code for the Resido React Native application.

## 🚀 Quick Start
1. `npm install`
2. `npx expo start`

## 📦 Key Screens
- `LoginScreen`: OTP input with high-visibility mode.
- `ProfileScreen`: Bio management and photo uploads.
- `JobProfileScreen`: Professional service registration.
- `ServiceSearchScreen`: Discovery engine for nearby pros.
- `CreateCommunityScreen`: Admin tool for platform expansion.
